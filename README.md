# Sharifa — проверочная версия

Сайт: https://sahbanabdulaev445-cell.github.io/sharifa-preview/

Временная версия для проверки заказчиком. Открывается без GitHub и GPT.

- Учителя, ученики, группы и расписание.
- Выбор готовых групп для нескольких преподавателей без переноса учеников; отдельное расписание у каждого.
- Подсказки времени и настройка вариантов через карандаш.
- Оценки махраджа и таджвида, чтение по Корану или наизусть.
- Просмотр по группам или по учителям с раскрывающимися карточками и схемами.
- Создание и разделение филиалов, перенос групп вместе с учениками.
- Экспорт и восстановление резервной копии.

Данные проверки сохраняются в localStorage этого браузера. У каждого посетителя свои записи. Очистка данных браузера удаляет их; для сохранения используйте экспорт в разделе «Настройки». Общая серверная база в GitHub Pages отсутствует.

## Публикация

Изменения в main автоматически проверяются, собираются и публикуются GitHub Actions. Для этой ссылки исходные файлы на компьютер заказчика переносить не требуется.

Локальная сборка:

```sh
npm ci --ignore-scripts
node scripts/verify-pages-preview.mjs
node node_modules/vite/bin/vite.js build --config vite.pages.config.ts
```

Исходный серверный вариант сохранён в проекте; GitHub Pages использует отдельную сборку preview, повторно применяя те же правила проверки и переноса записей.
